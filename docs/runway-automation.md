# Runway API自動制作：仕様確認と課金しない実装

調査日2026-10-23（日本時間）。有料API・無料クレジット消費を伴う生成要求はゼロ。
取得元と本文ハッシュは [runway-source-check.json](runway-source-check.json)。
今回はオンボーディングではなくアプリケーション実装の追加。既存の編集・Release取り込み・6秒試作は維持する。

## 今回確認できた現行仕様

Runway公式の最新公開OpenAPIと公式Python SDKのmainを取得して確認した。
mainは変更されるため、この確認はアカウントごとの実利用可能性を保証しない。

|機能|今回取得した公式仕様|採用方針|
|---|---|---|
|動画生成|`POST /v1/text_to_video`、`gen4.5`、2〜10秒整数、`720:1280` / `1280:720`、`promptText` 1000 UTF-16単位以下|7果物×10秒、縦720p。既存編集で1080×1920へ変換するが、ネイティブ1080pとは扱わない|
|映像と同時の音声|gen4.5の入力にaudio指定はない|音声付きで返る前提を置かず、効果音を別生成する設計|
|効果音|`POST /v1/sound_effect`、`eleven_text_to_sound_v2`、duration 0.5〜30秒、loop false指定可|果物ごとに10秒の硬質音プロンプトを自動作成|
|状態照会|`GET /v1/tasks/{id}`、PENDING/THROTTLED/RUNNING/SUCCEEDED/FAILED/CANCELLED|IDを保存して同じタスクを照会。失敗しても別の有料生成を勝手に開始しない|
|認証・版|Bearer、`X-Runway-Version: 2024-11-06`|RESTアダプターに反映。生成→状態照会→HTTPS取得→音声付きマニフェスト→結合の内部エンジンも実装|
|クレジット換算|現行OpenAPIの説明は1 credit = $0.01|モデルごとの現行単価は別途確認が必要|
|Veo経由の音声|`veo3.1_fast`にaudio、duration 4/6/8秒、縦指定あり|10秒1本の要求は送れない。予算内の選択肢と断定しない|

SDKにモデルがあることを契約済み・無料・利用可能の証明にはしない。

## 10ドル制限と見積もり

既存調査の参考価格ではgen4.5は12 credits/秒（$0.12/秒）。
10秒×7本 = 840 credits = **映像だけで$8.40**。残る$1.60で効果音7本を賄えるかは、
現行の効果音料金を取得できていないため未確定。合計が$10以下と保証できない。
税・購入単位・為替・アカウント契約費等も別で、API使用額とクレジット購入額は同じとは限らない。

Veo Fast音声ありの既存参考価格$0.15/秒なら、各10秒を8秒+4秒の別ショットから切り出す場合は
84秒分 = $12.60で既に超過。通常Veoや再生成を無断で選んで予算を超えない。

`--mode plan` は音声料金を不明として `price-review-required` を返す。
モックの動画120 cents/本・音声10 cents/本、合計910 centsは**テスト専用の仮値であり実価格ではない**。
予算台帳は整数セントで計算し、計画全体を先に予約、1000 cents超過・不明価格・価格の変更を拒否する。
失敗・タイムアウトも返金済みと仮定せず予約を保持する。

**実課金CLI・実課金Actionsは公開していない。** 承認前の誤操作で課金できない。
RESTアダプターは既定でGETもPOSTも拒否する。モックはネットワーククライアントを使用しない。
現行単価を確認できず、サービス側の価格変動・他のクライアントによる支出もローカル台帳で制御できないため、
現時点で実請求の絶対上限を保証する実行経路を有効にはしない。
内部の実API用エンジンも、ユーザー承認・価格検証・サービス側上限検証の全条件を満たさない限り開始を拒否する。
本番Actionsへの接続・有効化は、これらの確認後の作業として残る。

## 課金しない自動制作の検証

[Runway automatic production - offline mock](https://github.com/shirura1-a11y/glass-fruit-ASMR/actions/workflows/runway-mock.yml)
→ Run workflow → `mock`。PC側の編集・素材アップロード・APIキーは不要。

自動で7つの映像タスクと7つの音声タスクを模擬し、各10秒の明示ラベル付きテスト素材とテスト音を作り、
既存編集系で70秒へ結合する。リアルなガラス映像・ガラス音を作るものではない。
Artifacts **SYNTHETIC-MOCK-NOT-AI-FOOTAGE-実行番号** にテストMP4とレポートを保存。
`plan` は生成もFFmpeg編集も行わず、要求内容と不足する料金確認を出す。

```bash
python -m glass_fruit.generate --mode plan
python -m glass_fruit.generate --mode mock --output-dir outputs/runway-mock
# 同じコマンドを再実行しても完了済みの14タスクを再送しない
python -m glass_fruit.generate --mode mock --output-dir outputs/runway-mock
```

`runway-mock-checkpoint` はSQLite台帳・生成済みファイル・ハッシュ・計画をまとめた再開用Artifacts。
Actionsの `resume_run_id` に前の実行番号を入れると復元して再開する。
台帳だけでなくファイルも必要。欠落・改変を検出したら勝手に生成し直さない。
チェックポイントが失効した場合は同じ制作の継続と見なせない。実運用では有効期間付きArtifactsや
不変のActionsキャッシュだけに課金台帳を依存させず、永続ストレージを確保する必要がある。

## エラー・再開・重複への対策

- プロンプト・モデル・尺・比率・API版からタスクキーを計算。
- SQLiteのトランザクションで予算予約と送信権を取得し、プロセスロックで同時編集を防ぐ。
- POST直前に状態を書き込み、応答喪失・クラッシュ時は「受付不明」で停止。生成POSTは自動再試行しない。
  公式仕様で生成POSTの冪等性キーを確認できなかったため、独自のキーを送るだけで安全とは扱わない。
- GETの429/5xx/通信エラーのみ最大4回まで、待ち時間上限30秒で再試行。401等は即停止。
- タスクID受領後は同じIDを照会。失敗・キャンセル・ポーリング期限切れを別生成で埋めない。
- 生成済みファイルと完成MP4はSHA-256で検証し、再実行時に再利用。
- APIキー、APIレスポンス本文、署名付き出力URLを台帳やログに保存しない。
- API認証を出力CDNへ転送せず、HTTPS検証を保持。非HTTPSへの転送・認証付き他ホスト転送を拒否。
  ダウンロードのみ最大4回再試行し、成功時に一時ファイルを置き換える。

## 承認後に必要な作業

1. Runway公式の映像・音声単価、モデル利用資格、商用条件、アカウント側の上限を確認する。
2. 音声込みで$10以内の具体的な計画を提示し、ユーザーの明示承認を得る。超過なら実行しない。
3. GitHub Settings → Secrets and variables → Actions に **RUNWAYML_API_SECRET** を登録する。
   値はチャット・ソース・workflow_dispatch入力・Artifactsへ入れない。今回のモックはこのSecretを読まない。
4. 保護されたGitHub Environment（例 `runway-paid`、承認者設定）と永続予算台帳を用意し、
   実装済みの生成・状態照会・HTTPS出力取得・自動結合エンジンを本番Actionsへ接続し、
   Secretの注入と復元を含む実運用経路を検証する。
5. 最初の1果物でガラスの物理表現と音の品質を評価する。映像と効果音の別生成は意味的同期を保証しない。
   映像・音声プロンプトは5秒付近で主切断をそろえるが、これは精密同期判定ではない。

実動画を生成した、音が自然に同期した、完全自動の有料制作がすぐ実行できるとは報告しない。
現在確認するのは公式API形状、料金の未確認箇所、安全な台帳・RESTアダプターとモック編集経路。

## 検証結果

- 既存42件と追加14件、合計56件成功。生成POSTは全てモック、実ネットワーク呼び出しなし。
- $10ちょうど・1セント超過・不明価格・価格変更・受付不明・再開・認証失敗・429再試行を検証。
- Secret非転送、HTTPS限定出力取得、生成POST再送禁止、ファイル改変検出、実課金開始ゲートを検証。
- 単独モック実行で70秒・1080×1920のMP4生成・全編デコード成功。初回14模擬要求、再実行0要求を確認。
- テスト内でもネットワークを禁止して70秒のモック生成・再開を実行（低解像度の検証用設定）。
- GitHub上のモックActions実行・Artifacts実ダウンロードは未検証。実写風生成品質・音の自然さは未評価。
- 実生成APIリクエスト0、実API使用料金$0。映像・効果音の現行合計料金が未確認のため実課金は無効のまま。
