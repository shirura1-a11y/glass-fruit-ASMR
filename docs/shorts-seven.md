# 7種類×10秒のYouTube Shorts制作

イチゴ → リンゴ → ブドウ → スイカ → オレンジ → キウイ → 桃、各10秒、合計70秒。
設定は `configs/shorts-seven.yaml`。1080×1920、9:16、30fps、H.264 + AAC。
元のASMR音声を使い、EQ・BGM・ナレーション・字幕を追加しない。AACへの再エンコードは行う。
元映像にすでに含まれる声・音楽・文字は自動除去できないので、入力側で仕様に合う素材を選ぶ。

## 一度設定して、後から素材を追加

既存Release **assets-001** をそのまま使える。`default.mp4` はイチゴとして自動分類される。
次の6本を、ZIPにせず同じReleaseへ順次添付する。1本が10秒以上必要。
複数の短い別ショットで合計10秒にしてもよい。長い素材は最初の10秒を使う。

|順番|Releaseの添付名|使う尺|
|---|---|---|
|1|既存 `default.mp4`（イチゴ）|10秒|
|2|`apple.mp4` または `リンゴ.mp4`|10秒|
|3|`grapes.mp4` または `ブドウ.mp4`|10秒|
|4|`watermelon.mp4` または `スイカ.mp4`|10秒|
|5|`orange.mp4` または `オレンジ.mp4`|10秒|
|6|`kiwi.mp4` または `キウイ.mp4`|10秒|
|7|`peach.mp4` または `桃.mp4`|10秒|

複数ショットなら `orange-01.mp4`、`orange-02.mp4` のようにする。ファイル名順に使用する。
未分類の名前はイチゴ扱いになるので、残り6種類には表の果物名を付ける。
同じ果物の古い素材も残っている場合は名前順に先に使われ得る。使わない添付を削除するか別のReleaseに分ける。

[Seven-fruit YouTube Shorts](https://github.com/shirura1-a11y/glass-fruit-ASMR/actions/workflows/shorts-seven.yml)
を開き **Run workflow**。`release_tag` の既定値は `assets-001` なので、そのまま実行できる。
以降は素材を追加して同じ操作を行えば、検査・結合は自動で進む。
`assets-001` のRelease公開・編集イベントにも対応する。ただし**添付追加だけで編集イベントが発火するとは限らない**。
また、既存タグのワークフロー選択などGitHub側の条件にも依存するため、既存ReleaseではRun workflowが確実。
イベント実行はリモート未検証。定期ポーリングや有料APIは使わない。

## 不足と完成の扱い

不足時は果物別の不足秒数とプロンプト計画をArtifactsに保存し、70秒完成MP4は作らない。
Summaryの不足量を確認して必要素材を追加する。同じ動画のループや静止画で埋めない。
イチゴの独立した6秒試作は可能なら先に保存するので、70秒の不足があっても取得できる。

7種類そろうと70秒に結合し、解像度・fps・音声/映像の尺・全編デコードを検査する。
成功した実行のArtifactsから **youtube-shorts-70s-実行番号** を取得する。
GitHub標準のZIPを開くと `GLASS-FRUIT.mp4` が入っている。
計画・取り込み対応表・検査結果は **glass-fruit-edit-実行番号** に保存する。
技術検査は写実性やガラス切断の自然さを保証しない。最後に視聴確認する。

## 果物を指定して準備を進める

```bash
source /workspace/.venvs/glass-fruit-asmr/bin/activate
cd /workspace/glass-fruit-ASMR
python -m glass_fruit --config configs/shorts-seven.yaml plan
python -m glass_fruit --config configs/shorts-seven.yaml plan --fruit kiwi
```

7種類を指定順にしたプロンプト、または指定果物のショット案と硬質なガラス音の指示を自動作成する。
`--fruit` はプロンプトの果物指定。編集順と尺は設定ファイルで決まり、プロンプトだけで素材が生成されるわけではない。
将来ほかの並びにする場合は設定の `scenes` を変更できる。既存の4種類70秒設定と6秒設定は維持。

**現在、実素材はイチゴのみ。残り6種類が各10秒不足しており、実写風70秒完成作品はまだない。**
素材生成は外部サービスから書き出して追加する段階が残る。有料API・課金・契約は実行しない。
将来APIを追加する場合も、費用・上限・試行回数を提示してユーザーの事前承認を得る。
GitHub Actions/Artifactsのアカウント利用枠・保存料金は別途確認する。
